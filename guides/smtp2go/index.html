Send from your own domain in Gmail with SMTP2GO

Setup guide · about 10 minutes · 1,000 emails a month free (200 a day)

Gmail is ending “Send mail as” for addresses it doesn't host (Google Help). With SMTP2GO and SendAs Bridge you keep writing in Gmail, and your email is sent from you@yourdomain.com through your own SMTP2GO account.

Popular with former Gmail "Send mail as" users. Simple verified-sender setup.

1. Set up SMTP2GO

  1. Create a free account at smtp2go.com.
  2. Go to Sending → Verified Senders → Add a sender domain, and add the three CNAME records it shows.
  3. Go to Sending → API Keys → Add API Key. Make sure the "Emails" permission is on, then copy the key (it starts with api-).
If your account was created in a specific region, pick the same API region in SendAs Bridge.

2. Connect it to SendAs Bridge

  1. Install SendAs Bridge (or for Edge). The setup page opens automatically.
  2. Choose SMTP2GO and fill in:
    • API key — SMTP2GO → Sending → API Keys → Add API Key. Allow the "Emails" permission.
    • API region
  3. Click Connect. Chrome asks to let SendAs Bridge reach SMTP2GO's API — click Allow. The key is checked right away.
  4. Add your address (for example you@yourdomain.com) and your name.
  5. Run the domain check and fix anything marked ❌, then send yourself a test. Open it in Gmail: SendAs Bridge shows Gmail's SPF, DKIM and DMARC verdict.

3. Send from Gmail

Open Gmail, start a new email or a reply, and pick your address in the From row at the top of the compose window. Replies to mail sent to your domain select it automatically. Click Send; a copy appears in your Gmail conversation.

What's supported with SMTP2GO

  • Inline pictures: yes, sent as real inline images
  • Reply threading: yes (In-Reply-To and References headers)
  • Maximum email size: about 50 MB, up to 100 recipients
