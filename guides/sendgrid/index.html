Send from your own domain in Gmail with SendGrid

Setup guide · about 15 minutes · Free trial, then paid plans (Twilio SendGrid)

Gmail is ending “Send mail as” for addresses it doesn't host (Google Help). With SendGrid and SendAs Bridge you keep writing in Gmail, and your email is sent from you@yourdomain.com through your own SendGrid account.

Use it if you already have a SendGrid account.

1. Set up SendGrid

  1. Sign in to Twilio SendGrid.
  2. Go to Settings → Sender Authentication → Authenticate Your Domain, and add the CNAME records it shows.
  3. Go to Settings → API Keys → Create API Key. Choose Restricted Access with "Mail Send" on, and copy the key (it starts with SG.).

2. Connect it to SendAs Bridge

  1. Install SendAs Bridge (or for Edge). The setup page opens automatically.
  2. Choose SendGrid and fill in:
    • API key — SendGrid → Settings → API Keys → Create API Key with "Mail Send" access.
    • Region
  3. Click Connect. Chrome asks to let SendAs Bridge reach SendGrid's API — click Allow. The key is checked right away.
  4. Add your address (for example you@yourdomain.com) and your name.
  5. Run the domain check and fix anything marked ❌, then send yourself a test. Open it in Gmail: SendAs Bridge shows Gmail's SPF, DKIM and DMARC verdict.

3. Send from Gmail

Open Gmail, start a new email or a reply, and pick your address in the From row at the top of the compose window. Replies to mail sent to your domain select it automatically. Click Send; a copy appears in your Gmail conversation.

What's supported with SendGrid

  • Inline pictures: yes, sent as real inline images
  • Reply threading: yes (In-Reply-To and References headers)
  • Maximum email size: about 30 MB, up to 1000 recipients
