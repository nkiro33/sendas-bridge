Send from your own domain in Gmail with Mailjet

Setup guide · about 15 minutes · 6,000 emails a month free (200 a day)

Gmail is ending “Send mail as” for addresses it doesn't host (Google Help). With Mailjet and SendAs Bridge you keep writing in Gmail, and your email is sent from you@yourdomain.com through your own Mailjet account.

European provider with a free plan.

1. Set up Mailjet

  1. Create a free Mailjet account (6,000 emails a month).
  2. Go to Account settings → Senders & Domains → Add domain, and add the SPF and DKIM records it shows.
  3. Go to Account settings → API Key Management and copy both the API Key and the Secret Key.

2. Connect it to SendAs Bridge

  1. Install SendAs Bridge (or for Edge). The setup page opens automatically.
  2. Choose Mailjet and fill in:
    • API key — Mailjet → Account settings → API Key Management. Copy the API key and the Secret key.
    • Secret key
  3. Click Connect. Chrome asks to let SendAs Bridge reach Mailjet's API — click Allow. The key is checked right away.
  4. Add your address (for example you@yourdomain.com) and your name.
  5. Run the domain check and fix anything marked ❌, then send yourself a test. Open it in Gmail: SendAs Bridge shows Gmail's SPF, DKIM and DMARC verdict.

3. Send from Gmail

Open Gmail, start a new email or a reply, and pick your address in the From row at the top of the compose window. Replies to mail sent to your domain select it automatically. Click Send; a copy appears in your Gmail conversation.

What's supported with Mailjet

  • Inline pictures: yes, sent as real inline images
  • Reply threading: headers are sent; not yet confirmed with this provider
  • Maximum email size: about 15 MB, up to 50 recipients
