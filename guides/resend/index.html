Send from your own domain in Gmail with Resend

Setup guide · about 10 minutes · 3,000 emails a month free (100 a day)

Gmail is ending “Send mail as” for addresses it doesn't host (Google Help). With Resend and SendAs Bridge you keep writing in Gmail, and your email is sent from you@yourdomain.com through your own Resend account.

Developer-friendly, quick domain setup. Good default.

1. Set up Resend

  1. Create a free account at resend.com.
  2. Go to Domains → Add Domain and enter your domain (for example yourdomain.com).
  3. Add the DNS records Resend shows (a DKIM TXT record, plus an MX and a TXT record on send.yourdomain.com). On Cloudflare you can click "Auto configure". Wait until the domain says Verified.
  4. Go to API Keys → Create API Key. Choose "Sending access", pick your domain, and copy the key (it starts with re_).
Unverified Resend accounts can only send to your own address, so finish the domain step first.

2. Connect it to SendAs Bridge

  1. Install SendAs Bridge (or for Edge). The setup page opens automatically.
  2. Choose Resend and fill in:
    • API key — Resend → API Keys → Create API Key. "Sending access" is enough; "Full access" also lets SendAs Bridge check your domain.
  3. Click Connect. Chrome asks to let SendAs Bridge reach Resend's API — click Allow. The key is checked right away.
  4. Add your address (for example you@yourdomain.com) and your name.
  5. Run the domain check and fix anything marked ❌, then send yourself a test. Open it in Gmail: SendAs Bridge shows Gmail's SPF, DKIM and DMARC verdict.

3. Send from Gmail

Open Gmail, start a new email or a reply, and pick your address in the From row at the top of the compose window. Replies to mail sent to your domain select it automatically. Click Send; a copy appears in your Gmail conversation.

What's supported with Resend

  • Inline pictures: yes, sent as real inline images
  • Reply threading: yes (In-Reply-To and References headers)
  • Maximum email size: about 40 MB, up to 50 recipients
