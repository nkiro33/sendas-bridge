Send from your own domain in Gmail with Amazon SES

Setup guide · about 20 minutes, plus AWS approval · About $0.10 per 1,000 emails (3,000 a month free for the first 12 months)

Gmail is ending “Send mail as” for addresses it doesn't host (Google Help). With Amazon SES and SendAs Bridge you keep writing in Gmail, and your email is sent from you@yourdomain.com through your own Amazon SES account.

Cheapest at volume. New accounts start in a sandbox until AWS approves production access.

1. Set up Amazon SES

  1. Sign in to the AWS console and open Amazon SES in the region you want (for example us-east-1).
  2. Go to Identities → Create identity → Domain, keep Easy DKIM on, and add the three CNAME records it shows.
  3. In SES → Account dashboard, request production access. Until AWS approves it, SES only sends to addresses you have verified.
  4. Open IAM → Users → Create user. Attach a policy that allows only ses:SendEmail and ses:SendRawEmail.
  5. Open the user → Security credentials → Create access key ("Application running outside AWS"). Copy the Access key ID and Secret access key.
SES costs about $0.10 per 1,000 emails. AWS asks for a payment card when you sign up.

2. Connect it to SendAs Bridge

  1. Install SendAs Bridge (or for Edge). The setup page opens automatically.
  2. Choose Amazon SES and fill in:
    • Access key ID — Create an IAM user with only the "ses:SendEmail" and "ses:SendRawEmail" permissions, then create an access key for it.
    • Secret access key
    • Region
  3. Click Connect. Chrome asks to let SendAs Bridge reach Amazon SES's API — click Allow. The key is checked right away.
  4. Add your address (for example you@yourdomain.com) and your name.
  5. Run the domain check and fix anything marked ❌, then send yourself a test. Open it in Gmail: SendAs Bridge shows Gmail's SPF, DKIM and DMARC verdict.

3. Send from Gmail

Open Gmail, start a new email or a reply, and pick your address in the From row at the top of the compose window. Replies to mail sent to your domain select it automatically. Click Send; a copy appears in your Gmail conversation.

What's supported with Amazon SES

  • Inline pictures: yes, sent as real inline images
  • Reply threading: yes (In-Reply-To and References headers)
  • Maximum email size: about 40 MB, up to 50 recipients
