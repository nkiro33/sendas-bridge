Send from your own domain in Gmail with Postmark

Setup guide · about 15 minutes, plus approval · 100 emails a month free; new accounts need approval before sending to anyone

Gmail is ending “Send mail as” for addresses it doesn't host (Google Help). With Postmark and SendAs Bridge you keep writing in Gmail, and your email is sent from you@yourdomain.com through your own Postmark account.

Excellent deliverability for personal mail. Paid plans from $15/month.

1. Set up Postmark

  1. Create a Postmark account (100 free emails a month).
  2. Go to Sender Signatures → Add Domain, and add the DKIM and Return-Path records it shows.
  3. Request account approval from the Postmark dashboard; new accounts can only send to their own domain until approved.
  4. Open Servers → your server → API Tokens and copy the Server API token.

2. Connect it to SendAs Bridge

  1. Install SendAs Bridge (or for Edge). The setup page opens automatically.
  2. Choose Postmark and fill in:
    • Server API token — Postmark → Servers → your server → API Tokens. Use the Server token, not the Account token.
  3. Click Connect. Chrome asks to let SendAs Bridge reach Postmark's API — click Allow. The key is checked right away.
  4. Add your address (for example you@yourdomain.com) and your name.
  5. Run the domain check and fix anything marked ❌, then send yourself a test. Open it in Gmail: SendAs Bridge shows Gmail's SPF, DKIM and DMARC verdict.

3. Send from Gmail

Open Gmail, start a new email or a reply, and pick your address in the From row at the top of the compose window. Replies to mail sent to your domain select it automatically. Click Send; a copy appears in your Gmail conversation.

What's supported with Postmark

  • Inline pictures: yes, sent as real inline images
  • Reply threading: yes (In-Reply-To and References headers)
  • Maximum email size: about 10 MB, up to 50 recipients
