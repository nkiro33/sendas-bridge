Send from your own domain in Gmail with Mailgun

Setup guide · about 15 minutes · 100 emails a day on the free plan

Gmail is ending “Send mail as” for addresses it doesn't host (Google Help). With Mailgun and SendAs Bridge you keep writing in Gmail, and your email is sent from you@yourdomain.com through your own Mailgun account.

Sends the exact message SendAs Bridge builds (raw MIME).

1. Set up Mailgun

  1. Create a Mailgun account (the free plan sends 100 emails a day).
  2. Go to Send → Domains → Add new domain. Using your main domain or a subdomain like mg.yourdomain.com both work.
  3. Add the SPF and DKIM records Mailgun shows and click Verify.
  4. Go to Settings → API Security and create an API key (a domain "Sending key" works too). Note whether your account is in the US or EU region.
If you added mg.yourdomain.com, you can still send as you@yourdomain.com; enter mg.yourdomain.com as the sending domain.

2. Connect it to SendAs Bridge

  1. Install SendAs Bridge (or for Edge). The setup page opens automatically.
  2. Choose Mailgun and fill in:
    • API key — Mailgun → Settings → API Security → create a key. A domain "Sending key" also works.
    • Sending domain — Exactly as it appears in Mailgun → Sending → Domains.
    • Region
  3. Click Connect. Chrome asks to let SendAs Bridge reach Mailgun's API — click Allow. The key is checked right away.
  4. Add your address (for example you@yourdomain.com) and your name.
  5. Run the domain check and fix anything marked ❌, then send yourself a test. Open it in Gmail: SendAs Bridge shows Gmail's SPF, DKIM and DMARC verdict.

3. Send from Gmail

Open Gmail, start a new email or a reply, and pick your address in the From row at the top of the compose window. Replies to mail sent to your domain select it automatically. Click Send; a copy appears in your Gmail conversation.

What's supported with Mailgun

  • Inline pictures: yes, sent as real inline images
  • Reply threading: yes (In-Reply-To and References headers)
  • Maximum email size: about 25 MB, up to 1000 recipients
